# HELIVIA GUARDIAN - Help Finds You

**Track: Alexa+ Track | Amazon Build, Ship, Shape Hackathon 2026**

India's first hands-free women's safety skill. Just say "Alexa, emergency" - no phone touch needed.

### What it does
- 10m SOS Proof: Auto video + audio + GPS location
- Emergency contacts auto-call
- AI danger prediction
- Nearby community alert

### Demo
Replit: replit.com/@jsanika901/HELIVIA-GUARDIAN

### Built With
Alexa+ Skills Kit, React, TypeScript, WebRTC, Geolocation

### Inspiration
Women's safety needs "Help Finds You" not "Find Help". When you can't touch phone, Alexa+ is lifeline.
